# DAERI 업무

설치된 `runtime` MCP 서버의 실제 도구 이름과 호스트 namespace를 확인한다.
한국어로 확인한 결과·필요한 선택·복구 방법을 설명하고, 업무 판단·분석·실행은 공용 서비스에 맡긴다.

## 프로젝트와 업무

인증과 사용자 자격은 호스트의 MCP 회사 로그인 경로에서 처리하고 공용 프로젝트의 연결을 사용한다.

`daeri_projects`의 허용 목록에서 프로젝트를 선택한다.
선택이 불명확하면 사용자에게 확인하고, 새 업무는 `daeri_work`에 목표·조건·원하는 결과를 전달한다.
기존 업무는 `daeri_tasks`·`daeri_status`에서 확인한 같은 프로젝트·자신의 `task_id`로 이어간다.
선택값은 현재 대화에 연결하고 서버의 결과·미충족 조건을 안내한다.
파일이 필요하면 `daeri_files`의 실제 목록에서 선택하고 `daeri_download`로 발급받은 링크를 표시한다.
링크 만료에는 현재 업무의 다운로드를 다시 요청한다.

## 프로젝트 연결

연결 도구가 공개된 서버에서는 `daeri_connections`로 현재 프로젝트의 연결을 확인한다.
연결 등록 요청에는 `daeri_connectors`의 실제 카탈로그에서 커넥터를 선택한다.
기존 연결은 실제 목록의 ID를, 새 연결은 목적을 나타내는 ID를 사용한다.
관리 권한이 있는 사용자의 등록·갱신은 `daeri_connect`로 서버가 제공하는 호스트 확인창을 연다.
접속 정보·기존 비밀 참조·허용된 원격 인증 별칭은 사용자가 확인창에 입력한다.
도구 입력은 프로젝트·연결·커넥터 식별자로 구성하고 이미지·역할·endpoint·자격은 서버가 관리한다.

확인창 취소·미지원·시간 초과에는 기존 연결을 유지하고 다시 확인할 경로를 안내한다.
관리 권한 부족은 프로젝트 관리자에게 등록을 요청하도록 안내한다.
연결 목록의 `READY`는 마지막 등록 때 도구 발견을 확인한 상태이며 현재 리소스 접근은 승인한 업무의 호출 결과로 확인한다.
일부 등록이 실패하면 `daeri_connections`에서 저장 상태를 확인하고 같은 연결 ID·커넥터로 재시도한다.

## 계획 확인

`awaiting_confirmation`이면 현재 계획을 설명하고 `daeri_confirm`으로 호스트 사용자 확인창을 연다.
확인창의 `approve`는 제시한 계획 승인, `revise`는 수정 요청, `reject`는 거절이다.
설명 입력은 수정 사항·추가 조건이며, 내용이 있으면 승인 선택이어도 수정 계획을 다시 확인한다.

승인은 사용자가 호스트의 확인창에서 선택한 응답으로 전달한다.
확인창 닫기·미지원·시간 초과·연결 종료에는 원래 대기를 유지하고 사용자가 다시 확인할 경로를 안내한다.
목표·범위가 바뀌면 기존 업무에 변경 내용을 전달하고 새 계획을 확인한다.

## 결과와 복구

실패에는 `daeri_status`로 현재 업무·계획·대기를 확인한다.
저장한 응답의 상태 반영 실패는 `daeri_recover`로 복구한다.
처리할 수 없는 도구 대기, 응답 원본이 파일에 보관된 경우, 세션 만료나 실행 불명확에는 기존 실행의 종료와 실제 효과를 확인하고 `daeri_recover(restart=true)`의 사용자 확인창으로 연결한다.
확인 후 같은 업무의 새 계획을 제시하면 다시 `daeri_confirm`을 사용한다.
로그인·권한 변화에는 현재 인증과 프로젝트 선택을 확인한다.
결과 이후 피드백은 같은 업무에 전달하고 기억·파일의 검색 가능성은 서비스 응답에서 확인한다.
