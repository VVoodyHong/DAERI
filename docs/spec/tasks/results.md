# 실행 이력과 결과 명세

상태: 결과·근거·검증 동작 설계 제안

수행 근거와 완료 여부를 확인할 관리자·설계 담당자·에이전트를 위한 명세다.

이 문서는 호출 이력의 보존과 결과물·근거·검증의 제공 계약을 정의한다.
업무 상태와 재개 조건은 [업무 흐름](workflow.md)을 따른다.
계획 버전과 승인 기록은 [승인 명세](approval.md)를 따른다.

## 실행 이력

각 호출에 리소스·기능·입력, 계획 버전과 승인 또는 정책 결정을 연결한다.
시도 번호, 시작·종료 시각, 결과·오류도 연결한다.
이 기록은 대화 기록과 별도로 보존한다.

비밀값은 저장하지 않는다.
민감한 입력·결과의 보관·열람·보존 기간은 부처별 설정으로 정한다.

## 결과물과 근거

결과물은 답변, 추출 파일, 분석 보고서, 코드 변경안, 작업 기록 등 요청에 따른다.
사용한 대상·조건과 실제 수행 내역을 제공한다.
완료 조건의 충족 여부와 원본 위치·조회 시점·실행 참조도 제공한다.

리소스 호출이 반환할 원본 참조와 잘림·페이지 정보는 [리소스 계약](../resources/contract.md)에 있다.

## 검증과 완료 판단

필터·기간의 정확성, 누락·잘림, 원본과 결과의 대응을 검증한다.
변경은 가능하면 변경 후 상태나 테스트로 확인한다.
자연어 설명만으로 성공을 확정하지 않는다.

실패·부분 결과·성공 여부 불명확을 보고하는 예시는 [가상 사례](scenarios.md)에 있다.
