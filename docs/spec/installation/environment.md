# 로컬 실행 환경과 설치 흐름

상태: 확정 설치 요구사항 + 구현 방식 설계 제안

설치 기능을 기획·검토하는 사람과 개발 에이전트를 위한 명세다.

이 문서는 향후 사용자에게 제공할 의존성 검사와 설치 기능의 계약이다.
현재 개발자의 PC에서 실행할 설치 지시나 설치 완료 안내가 아니다.
패키지 배포와 업데이트는 [배포 명세](distribution.md)에 있다.

## 확정 설치 조건

사용자 PC에는 Codex 또는 Claude Code만 준비되어 있다고 가정한다.
DAERI 실행에 필요한 프로그램의 존재와 지원 버전을 확인해야 한다.
없거나 호환되지 않으면 설치 기능으로 준비해야 한다.

Windows와 macOS를 지원하도록 설계한다.
최초 구현·실행 검증은 사용자의 Mac에서 진행한다.

## 의존성 검사 대상

| 항목 | 현재 제안 |
|---|---|
| 호스트 | 사용자가 선택한 Codex 또는 Claude Code |
| 로컬 런타임 | Python + 공식 MCP SDK |
| 환경 준비 | uv 기반 사용자별 환경 |
| 리소스 SDK | [초기 어댑터의 SDK 제안](../resources/initial-adapters.md#대상별-기능과-sdk) |
| 상태 보존 | SQLite |
| 인증별 도구 | 인증 방식별 외부 도구 |
| 다운로드·실행 진입점 | macOS 기본 shell·다운로드 수단, Windows 기본 PowerShell |

위 프로그램은 구현 후보이며 필수 프로그램과 지원 버전을 확정한 목록은 아니다.
필요한 프로그램·패키지와 지원 버전은 [개발 원칙](../../rules/development.md)에 따라 추후 dependency 목록에서 관리한다.
호스트별 필수 기능과 호환성은 배포 전에 검증한다.

uv가 미설치일 때 준비하는 진입점도 필요하다.
Python과 SQLite의 필수 기능은 실제로 확인한다.
선택한 인증 방식이 외부 도구를 요구하면 별도로 확인하고 준비한다.

다운로드·실행 진입점은 OS의 기본 도구를 활용하는 제안이다.
실제 최소 OS와 실행 정책을 검증해야 한다.

## 로컬 프로그램과 원격 리소스의 구분

초기 SDK 방식의 원격 연결에는 로컬 PostgreSQL·Redis 서버가 필수는 아니다.
AWS CLI, Docker, Git도 모두 반드시 필요한 것은 아니다.

Git은 저장소를 내려받는 배포 경로나 소스 변경 기능에서 필요할 수 있다.
AWS CLI는 AWS SSO profile 로그인 등 인증 방식에 따라 필요할 수 있다.
의존성은 실행·배포·인증 기능별로 구분해 검증한다.

실행 환경 설치는 원격 자원의 생성·변경·업그레이드를 포함하지 않는다.
원격 제품의 기능과 권한은 [리소스 공통 계약](../resources/contract.md)에 따라 진단한다.

## 향후 설치 흐름

1. **진입:** 호스트, OS·CPU, 사용자별 설치 위치와 배포 버전을 파악한다.
2. **검사:** 필요한 실행 파일의 존재뿐 아니라 실제 경로·버전·기능·호환성을 확인한다.
3. **준비:** dependency 목록과 검증한 잠금 정보에 따라 필요한 런타임·의존성을 사용자별 환경에 설치한다.
   시스템 Python·다른 프로젝트 환경·shell profile을 덮어쓰지 않는 방식을 기본값으로 제안한다.
4. **검증:** SDK import, SQLite 기능, MCP 시작과 호스트 연결을 실제 확인한다.
   검사 실패를 성공으로 기록하지 않는다.
5. **연결 설정:** 리소스 주소와 인증 참조를 사용자 로컬 설정으로 받는다.
   접속·권한·원격 버전과 기능을 진단한다.
6. **사용 준비:** 설치한 버전과 진단 결과를 보여 주고 [업무 흐름](../tasks/workflow.md)으로 이동한다.
   업무 데이터 조회·변경에는 [승인 명세](../tasks/approval.md)를 적용한다.

중간 실패 후 재실행할 수 있어야 한다.
정상 환경을 매 시작마다 다시 설치하지 않는다.
설치 다운로드는 검증된 배포 출처와 버전·무결성 정보를 사용한다.

## 인증과 자동 준비가 불가능한 조건

연결 주소·권한·인증은 사용자 로컬 설정의 참조로 처리한다.
비밀값을 모델에 제공하거나 문서에 기록하지 않는다.
인증 참조와 연결 실패의 공통 계약은 [리소스 공통 계약](../resources/contract.md)에 있다.

인증·VPN·사내 인증서·보안 정책으로 자동 준비가 불가능할 수 있다.
이때 필요한 사용자 조치와 미완료 이유를 설명한다.
사내 정책을 우회하거나 원격 자원을 자동 변경해 설치를 완료하지 않는다.

비공개 저장소 접근 인증과 플러그인 출처 정책은 [배포 명세](distribution.md)를 따른다.

## 아직 검증하지 않은 항목

지원할 OS·CPU와 호스트·런타임·리소스 SDK의 호환성은 아직 검증하지 않았다.
인증별 외부 도구와 OS별 다운로드·실행 제한도 미결이다.

현재 프로그램 검사나 설치, 실제 호스트·리소스 연결 검증은 수행하지 않았다.
