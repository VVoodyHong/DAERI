# 초기 어댑터 명세

상태: 확정 연동 대상 + 최초 기능·SDK 설계 제안

최초 연동 기능과 지원 범위를 검토하는 사람과 개발 에이전트를 위한 명세다.

최초 연동 대상은 **PostgreSQL, Redis, AWS, GitLab**으로 확정했다.
이 문서는 각 대상의 최초 기능, SDK와 권한 경계 제안을 소유한다.
공통 등록부·호출·실패 계약은 [리소스 공통 계약](contract.md)에 있다.

아래의 SDK와 제한된 읽기 기능은 최초 검증을 위한 제안이다.
아직 구현하지 않았다.

## 대상별 기능과 SDK

| 대상 | SDK 제안 | 최초 기능 | 검사할 경계 |
|---|---|---|---|
| PostgreSQL | `psycopg[binary]` | 메타데이터, 구조화된 조회·집계 | DB·스키마·테이블·필드·필터·행 수·시간 |
| Redis | `redis` | 제한된 키 탐색, 타입·TTL·문자열 구간 읽기 | key prefix·반환 키·후속 읽기·검색량·바이트 |
| AWS | `boto3` | 실제 계정·리전 확인, 제한된 EC2 인스턴스 조회 | account·region·기능·resource ID |
| GitLab | `python-gitlab` | 저장소 tree·파일 읽기·검색 | origin·project·ref·path·commit snapshot |

SDK 선택과 지원 버전은 [개발 원칙](../../rules/development.md)에 따라 추후 dependency 목록에서 관리한다.
SDK와 전이 의존성은 구현 전에 실제 검증한 뒤 잠근다.
세부 기능은 아직 미결이다.
설치 여부와 호환성을 검사하는 흐름은 [실행 환경 명세](../installation/environment.md)에 있다.

## PostgreSQL의 경계

허용한 스키마·테이블을 대상으로 메타데이터와 구조화된 조회·집계를 제공하는 것을 제안한다.
DB·필드·필터·행 수·실행 시간을 검사한다.

제한된 DB 권한과 read-only transaction을 적용한다.
자유 SQL은 최초 기능에 자동 포함되지 않는다.

## Redis의 경계

제한된 키 탐색과 타입·TTL·문자열 구간 읽기를 제공하는 것을 제안한다.
승인 key prefix로 탐색 조건을 구성한다.

반환 키와 후속 읽기에서도 범위를 다시 검사한다.
반환 키 수, 총 검색량과 반환 바이트를 제한한다.
자유 Redis 명령은 최초 기능에 자동 포함되지 않는다.

## AWS의 경계

실제 계정·리전 확인과 제한된 EC2 인스턴스 조회로 시작하는 것을 제안한다.
승인한 account·region·기능·resource ID를 검사한다.

다른 계정·리전으로 범위를 자동 확대하지 않는다.
AWS 모든 서비스는 최초 기능에 자동 포함되지 않는다.
초기 AWS 서비스의 세부 지원 범위는 아직 미결이다.

## GitLab의 경계

승인된 프로젝트의 저장소 tree·파일 읽기·검색을 제공하는 것을 제안한다.
origin·project·ref·path를 검사한다.
승인 ref가 가리키는 commit snapshot을 고정한다.

GitLab 변경 기능은 최초 기능에 자동 포함되지 않는다.
검색의 지원 여부와 부분 결과 표시는 [리소스 공통 계약](contract.md)을 따른다.

## 읽기 기능으로 시작하는 이유와 확장

읽기 기능으로 먼저 연결과 승인 경계를 검증하는 제안이다.
제품 전체의 변경 업무를 제외하는 요구는 아니다.

변경 기능은 변경 범위와 실제 권한을 정의해 추가한다.
중복 방지, 변경 후 검증, 실패·복구 계약도 정의한다.
승인 범위와 수정 계획은 [승인 명세](../tasks/approval.md)를 따른다.
