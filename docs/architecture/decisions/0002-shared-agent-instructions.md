# ADR-0002: AGENTS.md를 공통 지침의 단일 원본으로 사용

상태: 채택 · 근거: 사용자의 문서 원본 지정

## 배경

개발은 Codex와 Claude Code 양쪽에서 진행할 수 있다.
도구마다 공통 규칙을 복사하면 수정 누락과 상충이 생긴다.
상세 명세까지 루트 지침에 넣으면 매 작업에 필요한 문맥이 불필요하게 커진다.

## 검토한 대안

| 대안 | 영향 |
|---|---|
| AGENTS와 CLAUDE에 같은 지침 복사 | 두 원본의 동기화가 필요 |
| CLAUDE가 AGENTS를 가져오기 | 한 원본만 수정, 두 호스트의 진입점 유지 |
| CLAUDE를 AGENTS의 심볼릭 링크로 만들기 | Windows의 링크 생성·Git 체크아웃 환경에 따른 제약 |

## 선택

공통 기본 지침과 작업 진입점은 루트 [AGENTS.md](../../../AGENTS.md)에서 정리한다.
[CLAUDE.md](../../../CLAUDE.md)는 `@AGENTS.md` 한 줄의 일반 파일로 유지한다.

상세 작업 규칙은 `docs/rules/`, 제품 규격은 `docs/spec/`의 주제별 정본에 둔다.
AGENTS는 필수 읽기·갱신 경로를 지정한다.

## 영향

각 규칙은 담당 정본 한 곳에서 수정하며 호스트별로 복사하지 않는다.
호스트별 자동 메모리와 추가 플러그인 없이도 공유 가능한 문맥이 저장소에 남는다.

상세 문서를 항상 기억하거나 모든 규칙이 자동 강제된다는 보장은 없다.
관련 파일을 실제 읽는 재개 절차와 상태 기록으로 보완한다.

로딩 방식의 공식 근거와 확인 방법은 [문맥 복구 설명](../../development/agent-context.md)에 있다.
상세 문서의 원본 위치는 [문서 구조와 정본](../../development/documentation-architecture.md)에 있다.
