# DAERI list-profiles

기본 응답은 한국어이며 사용자가 다른 언어를 지정하면 따른다.
등록 목록만 조회하며 현재 대화의 선택을 바꾸지 않는다.
저장 정보의 의미는 [profile 명세](../../docs/spec/configuration/profiles.md)를 따른다.
이 Skill에서 `../../`는 설치된 플러그인 루트다.

1. 플러그인 루트의 준비된 Python으로 `-I -m daeri.cli profile list`를 실행한다.
   두 OS 모두 `.venv/bin/python.exe`를 절대 경로로 지정하고 [profile의 관리 실행 기준](../profile/SKILL.md)을 따른다.
   명령은 플러그인 루트에서 실행하고 필요한 입력은 별도 인자로 전달한다.
   사용자 입력을 명령 문자열에 보간하지 않는다.
   실행 환경이 없으면 [setup](../setup/SKILL.md)을 안내하고 필요한 준비를 자동 실행하지 않는다.
2. 반환한 profile의 이름·등록된 리소스 범주를 최소한으로 요약한다.
   같은 이름·대상을 구분할 때만 식별자를 덧붙이고 전체 구성·접속 정보·인증 참조는 출력하지 않는다.
   목록이 비어 있으면 등록된 profile이 없다고 알리며 조회 실패를 빈 목록으로 바꾸지 않는다.
3. 필요하면 선택은 [profile](../profile/SKILL.md), 생성·수정은 setup에서 진행할 수 있다고 안내하고 끝낸다.

목록 요청으로 profile 생성·수정·선택·업무 접수·리소스 호출을 하지 않는다.
설치·로그인·연결 진단·기억 검색이나 임베딩 모델 로딩도 시작하지 않는다.
저장된 연결 정보로 현재 인증·권한·실제 연결 성공을 추정하지 않는다.
